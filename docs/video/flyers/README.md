## Editar

Las composiciones HTML están en `source/`. Abrirlas en un navegador y modificar el texto externo o la composición. Las capturas y tipografías usan rutas relativas hacia los recursos conservados dentro de este mismo proyecto. La interfaz capturada permanece como imagen auténtica.

La limpieza conservó el código de la aplicación, los proyectos de presentación editables y sus fuentes. Los PNG se entregan por separado del video final.
